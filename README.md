# 🏎️ F1 Grand Prix Hub

**F1 Grand Prix Hub** is an Android application built using **Jetpack Compose**, **Retrofit**, and **Kotlin Coroutines**. It serves as an all-in-one companion app for Formula 1 enthusiasts, providing real-time race weekend schedules, championship standings, driver comparisons, session results, and live breaking news.

---

## ✨ Features

* **🏠 Home Dashboard:** View a live countdown timer to the next upcoming Grand Prix alongside breaking F1 news headlines powered by ESPN.
* **📰 In-App News Reader:** Read full news articles seamlessly inside the app using high-performance, dark-themed Chrome Custom Tabs.
* **📅 Interactive Race Calendar:** Track full season schedules, circuit details, local track times, and real-time weather conditions.
* **🏆 Championship Standings:** Switch dynamically between different seasons (2024–2026) to view updated Driver and Constructor standings.
* **📊 Driver Comparison Radar:** Compare two drivers side-by-side with automated strategic DNA analysis and historical metrics.
* **⏱️ Practice & Session Telemetry:** Drill down into FP1, FP2, FP3, Qualifying, and Race results with lap times, gaps, and team accents powered by OpenF1 and Ergast APIs.
* **🎬 Highlight Player:** Instantly launch official YouTube highlight reels for completed sessions.

---

## 🛠️ Tech Stack & Libraries

* **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
* **Networking:** [Retrofit 2](https://square.github.io/retrofit/) & Gson Converter
* **Async & Threading:** Kotlin Coroutines & `StateFlow` / Compose State
* **Image Loading:** [Coil 3](https://coil-kt.github.io/coil/)
* **In-App Browser:** AndroidX Browser (Custom Tabs)
* **Backend Integration:** Firebase Authentication & Firestore
* **APIs Used:**
  * **Ergast API:** Historical schedules, standings, and results.
  * **OpenF1 API:** Live session lap timings and weather data.
  * **ESPN API:** Breaking news headlines and articles.
  * **YouTube Data API v3:** Race highlight video embeds.

---

## 🚀 How to Run & Use the App

### Prerequisites
* **Android Studio** (Ladybug / Jellyfish or newer recommended)
* **Android SDK 34+**
* An Android Emulator or physical device running **Android 8.0 (API level 26)** or higher.
